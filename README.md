# Salaar Run

Chrome Dino-style runner reskinned with Prabhas from Salaar.

## Run locally

Open `index.html` directly in a modern browser, or serve the folder with a simple local server:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Controls

- `Space` or `↑`: Jump
- `↓` or `S`: Slide
- `M`: Toggle sound
- Mobile: Tap to jump or swipe down to slide
